# reu_ds_club_task_validator

## Запуск 

1. В docker-compose.yml в цель bot  
```BOT_TOKEN: "Токен бота сюды"```
2. Запуск Docker от админа (```Docker --version``` - выдаст версию)
3. ```docker-compose up -d``` - сборка проекта
(первый раз все будет скачиваться, в остальные разы будет быстрее)
4. ```docker-compose down``` - все контейнеры останавливаются и удаляются
